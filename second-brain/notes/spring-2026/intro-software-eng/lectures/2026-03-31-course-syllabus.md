## Key Concepts

**Philosophy**
- Test-Driven Development (TDD): write tests first, then code.
- Extreme Programming (XP), Kanban, Clean Code principles.
- All submissions via Blackboard Learn; latest submission before due date is graded.

**Assignments & Labs**
- Labs and assignments every week — they are sequential, so never skip one.
- Late penalty: up to 1 week late = −10%; 1–2 weeks late = −25%; not accepted after 2 weeks.
- No late submissions accepted for the **Final Project**.
