## Overview

Introduces the tree method (from Sets), the factorial function, the basic counting functions P(n,k)/C(n,k)/multinomial, combinatorial identities, the four-case word-counting table (permutations/combinations with/without repetition), the "salad/stars-and-bars" coding trick, cardinality theorems for set operations, inclusion-exclusion, derangements, the pigeonhole principle, and counting relations/functions.

## Key Concepts

### Factorial and basic counting functions
`0! ≔ 1`; `(n+1)! ≔ (n+1)(n!)`; theorem `n! = ∏_{k∈1..n} k`.

`P(n,k) ≔ n!/(n−k)!` — permutations of n objects taken k at a time (order matters, no repeats).
`C(n,k) ≔ n!/(k!(n−k)!) = P(n,k)/P(k,k) = (n choose k)` — combinations (order doesn't matter, no repeats).
`P(n; n₁,...,n_p) ≔ n!/(n₁!·n₂!·⋯·n_p!)` where `Σnₖ=n` — multinomial coefficient (permutations with repeated/indistinguishable items); invariant under permuting the lower indices.

All substitution into these formulas must be shown explicitly (`⟨n⟵3⟩` style), and theorem `P(n,k) ≥ C(n,k)` is proved via the standard SPf/EPf chain `LS = P(n,k)/C(n,k) = k! ≥ 1`.

Basic special values: `P(n,0)=1`, `P(n,1)=n`, `P(n,n)=P(n,n−1)=n!`, `C(n,0)=C(n,n)=1`, `C(n,1)=C(n,n−1)=n`.

### Combinatorial identities
| # | Name | Identity |
|---|---|---|
| 0 | Symmetry | `C(n,k)=C(n,n−k)` |
| 1 | Absorption | `C(n,k)=(n/k)·C(n−1,k−1)`, k≠0 |
| 2 | Trinomial Revision | `C(n,l)·C(n−l,k−l) = C(k,l)·C(n,k)` |
| 3 | Parallel Summation | `Σ_{k=0}^{n} C(m+k,k) = C(m+n+1,n)` |
| 4 | Upper Summation | `Σ_{k=0}^{n} C(k,m) = C(n+1,m+1)`, 0≤m≤n |
| 5 | (Vandermonde) Convolution | `Σ_{k=0}^{n} C(m,k)C(p,n−k) = C(m+p,n)`, n≤m+p |
| 6 | Addition (Pascal's rule) | `C(n,k)+C(n,k+1) = C(n+1,k+1)` |

### The four basic word-counting cases
For q-letter words on an alphabet of p distinct letters:

| | Order Matters (OM) | Order doesn't matter |
|---|---|---|
| **No repetition (RA)** | `P(p,q) = p!/(p−q)!` | `C(p,q) = p!/(q!(p−q)!)` |
| **Repetition allowed** | `p^q` | `C(p+q−1, q) = C(p+q−1, p−1)` |

Each case is derived via a **tree** (must be drawn/shown): with no-repeat+OM, slot i has `p−(i−1)` choices; with repeats+OM, every slot has p choices; with no-repeat+no-order, divide the OM count by `q!` (permutations of the chosen letters); with repeats+no-order, use the **"salad" stars-and-bars coding trick**: code each word as a binary string of `p−1` zeros (letter changes) and `q` ones (uses), total length `p+q−1`; the count is the number of ways to place the q ones (or p−1 zeros) among the slots.

### Cardinality theorems
`ν(S)` from Sets notes carries over. Comparison theorems: `S⊆T ⟹ ν(S)≤ν(T)`; nonempty injective functions `S→T` ⟹ `ν(S)≤ν(T)`; nonempty surjective functions `S→T` ⟹ `ν(S)≥ν(T)`; nonempty bijections ⟹ `ν(S)=ν(T)`.
Construction theorems: `ν(𝒫(S))=2^ν(S)`; `ν(S×T)=ν(S)·ν(T)`; `ν(S⊔T)=ν(S)+ν(T)`; `ν(S∪T)=ν(S)+ν(T)−ν(S∩T)`.

### Inclusion-exclusion principle
For 3 sets: `ν(S∪T∪U) = ν(S)+ν(T)+ν(U) − ν(S∩T)−ν(S∩U)−ν(T∩U) + ν(S∩T∩U)`.
General form: define `sₖ ≔ Σ (ν of all k-fold intersections)` over `1≤i₁<...<iₖ≤n`; then `ν(⋃_{p=1}^{n} A_p) = Σ_{p=1}^{n} (−1)^{p−1} sₚ` (alternating sum). De Morgan dual: `ν(⋂(A_p)ᶜ) = ν(𝒰) − Σ(−1)^{p−1}sₚ`.

### Derangements
A derangement is a permutation with no fixed points (`∀k, π(k)≠k`). `ν(Drngmnt(1..n)) = n! · Σ_{k=0}^{n} ((−1)^k / k!)`.

### Pigeonhole principle
If n pigeonholes hold n+1 pigeons, some hole has ≥2 pigeons. Generalized: if n pigeonholes hold kn+1 pigeons, some hole has ≥k+1 pigeons.

### Counting relations and functions
For `ν(S)=s`, `ν(T)=t`:
- `ν(Rln(S,T)) = 2^{st}`
- `ν(RflxRln(S)) = 2^{s²−s}`
- `ν(SymRln(S)) = 2^{(s²+s)/2}`
- (TrnsRln, EqvRln, PstRln formulas left as exercises in source — not given explicitly)
- `ν(Fnc(S,T)) = tˢ`
- `ν(InjFnc(S,T)) = C(t,s)·P(s,s) = C(t,s)·s!` (requires s≤t)
- `ν(SrjFnc(S,T)) = tˢ − Σ_{k=1}^{n−1} C(n,k)(n−k)ˢ` (requires s≥t; uses inclusion-exclusion)
- `ν(BijFnc(S,T)) = P(s,s) = s!` (requires s=t)

### Realizing arithmetic expressions as set cardinalities
Technique: given an arithmetic expression (e.g. `ab`, `(a+b)(c−d)`), construct sets whose sizes are the given numbers, realize the expression as `ν` of a set built via ×, ⊔, \, etc., then invent a real-world "journey" story (trains/buses between cities is the running example) whose answer is that cardinality. This "coding + story" skill is explicitly listed as an exam-style exercise.

## Summary
Counting builds directly on Sets (cardinality ν) and Relations/Functions (counting relations, injections, surjections, bijections). The central toolkit is: trees for generation, the four-case word-counting table for the basic P/C formulas, the stars-and-bars coding trick for repetition-allowed/order-doesn't-matter counts, and inclusion-exclusion for unions. Binomial coefficients `C(n,k)` reappear as the core object of the Binomial Theorem notes, and induction is the standard proof method for the combinatorial identities and inclusion-exclusion generalization.
