# Sets — CS/MATH Discrete Math (CCP)
**Date:** 2026-07-08
**Source:** Sets Notes.pdf

## Overview
Sets and membership are treated as primitive (undefined) notions. This note covers set specification, membership, subset/equality, the standard set operations (union, intersection, relative/absolute complement, product, coproduct), cardinality, the algebra-of-sets law table, and recursive specification of sequences via the factorial/Fibonacci examples. See `00-exam-conventions.md` for the required proof format, which is used throughout.

## Key Concepts

### Specifying sets
Two ways: (1) **listing**, e.g. `T ≔ {a,@,?,#}`; (2) **set-builder**, `S ≔ {x ∈ 𝒰 | P(x)}` — "the set of all x in the universe 𝒰 satisfying P." Distinguished sets: the universe `𝒰` and empty set `{ }` (the professor does **not** want `∅` used). Range notation: `p..q ≔ {n ∈ ℕ | p ≤ n ≤ q}` (also defined over ℤ). E.g. `2..5 = {2,3,4,5}`, `(−2)..3 = {−2,−1,0,1,2,3}`.

**J-number set-building drill** (common exam format): given a personal ID number's digits `J_k` for `k ∈ 1..8`, build sets like `A ≔ {J_k ∈ 0..9 | J_k < k}` by tabulating each k, its J_k value, whether the condition holds (Y/N), then listing the circled/qualifying values in increasing order.

### Membership (∈)
`x ∈ S` holds iff x is in the universe and either explicitly listed, or verifiably satisfies the defining property. Justify with "By inspection" for listed sets. For set-builder sets, justify membership as a conjunction, e.g. `3 ∈ {x∈ℝ|x>2}` because `(3∈ℝ)∧(3>2)`.
Quantifiers: `∃x∈S` = "there is some x in S"; `∄` = negation; `∀x∈S` = "for every x in S." Inference display: a horizontal bar with premises above, conclusion below; a double bar = biconditional (both directions valid).

### Inclusion / subset (⊆) and equality
`(A⊆B) :⟺ ∀x∈𝒰(x∈A ⟹ x∈B)`. To disprove inclusion, find a witness in A but not B. `A = B :⟺ (A⊆B)∧(B⊆A)`. For finite listed sets, order doesn't matter for equality.
Key theorems: `∀A∈𝒰({ }⊆A⊆𝒰)`; transitivity of ⊆; trichotomy-like law: `∀A,B (A⊂B)∨(A=B)∨(B⊂A)∨((A⊈B)∧(B⊈A))`.

### Operations on sets
| Operation | Definition |
|---|---|
| Power set | `𝒫(A) ≔ {S∈𝒰 \| S⊆A}` — set of all subsets of A. `ν(𝒫(A)) = 2^ν(A)`. |
| Union | `A∪B ≔ {x\|(x∈A)∨(x∈B)}` (inclusive or) |
| Intersection | `A∩B ≔ {x\|(x∈A)∧(x∈B)}` |
| Relative complement | `A\B ≔ {x\|(x∈A)∧(x∉B)}` — NOT symmetric: `A\B ≠ B\A` in general |
| Absolute complement | `Aᶜ ≔ 𝒰\A` (subscript universe if ambiguous) |
| Product (Cartesian) | `A⊓B ≔ A×B ≔ {(a,b)\|(a∈A)∧(b∈B)}` — computed via a **tree** |
| Diagonal | `Δ_S ≔ {(s,t)∈S×S \| s=t}` |
| Coproduct (disjoint union) | `A⊔B ≔ A⨃B ≔ (A×{0}) ∪ (B×{1})` — forces overlap elements to occur twice |

Power-set listing convention (exam-graded): list rows by subset size 0,1,2,...,n; every row except the last ends with a trailing comma.

**Relative complement algorithm** (must be shown step by step): scan left set element by element, ask "is it in the right set?" — if yes, cross it out (draw a horizontal line through it on paper); the surviving elements are the answer.

### Counting (cardinality)
`ν(S)` = number of elements in S. Key theorems:
- `S⊆T ⟹ ν(S)≤ν(T)`
- `ν(𝒫(S)) = 2^ν(S)`
- `ν(S×T) = ν(S)·ν(T)`
- `ν(S⊔T) = ν(S)+ν(T)`
- `ν(S∪T) = ν(S)+ν(T)−ν(S∩T)`
- `ν(S∪T∪U) = ν(S)+ν(T)+ν(U) − ν(S∩T) − ν(S∩U) − ν(T∩U) + ν(S∩T∩U)` (inclusion-exclusion; generalizes further — see Counting notes)

### Recursive specification (preview — full treatment in Induction/Recursion notes)
Factorial: `φ(0)≔1`; `φ(n+1)≔(n+1)φ(n)`. Fibonacci: `ρ(0)≔0, ρ(1)≔1`; `ρ(n+2)≔ρ(n+1)+ρ(n)`. Computing a value means "running backward": match input to the RcS pattern via explicit substitution `⟨n⟵k⟩`, unfold to the BC, then substitute values back up — show every line.

Indexed-family operations: `Σ_{k∈1..n}(a_k)`, `Π_{k∈1..n}(A_k)` (product of sets), `∐` (coproduct), `⋃`, `⋂`, `⋁` (disjunction), `⋀` (conjunction) — all defined by "run the operation as the index runs over the index set."

## Important Formulas / Definitions — Laws of the Algebra of Sets

(Correspondence with Propositional Calculus and Boolean Algebra is in `2026-07-08-boolean-algebra.md` and `2026-07-08-logic.md`.)

| Law | Sets form |
|---|---|
| Idempotent | `A∪A=A`, `A∩A=A` |
| Associative | `(A∪B)∪C=A∪(B∪C)`, `(A∩B)∩C=A∩(B∩C)` |
| Commutative | `A∪B=B∪A`, `A∩B=B∩A` |
| Distributive | `A∪(B∩C)=(A∪B)∩(A∪C)`, `A∩(B∪C)=(A∩B)∪(A∩C)` |
| Identity | `A∪{}=A`, `A∩𝒰=A`, `A∪𝒰=𝒰`, `A∩{}={}` |
| Complement | `A∪Aᶜ=𝒰`, `A∩Aᶜ={}`, `𝒰ᶜ={}`, `{}ᶜ=𝒰` |
| Uniqueness of complement | if `A∪X=𝒰` and `A∩X={}` then `X=Aᶜ` |
| Involution | `(Aᶜ)ᶜ=A` |
| De Morgan's | `(A∪B)ᶜ=Aᶜ∩Bᶜ`, `(A∩B)ᶜ=Aᶜ∪Bᶜ` |
| Absorption | `A∪(A∩B)=A`, `A∩(A∪B)=A` |
| Boundedness | `A∪𝒰=𝒰`, `A∩{}={}` |

Also: `A\B = A∩Bᶜ` (proved by the standard SPf/EPf inference-bar chain — see worked proof in source PDF, reproduced faithfully in `pdfs/Sets Notes.pdf`).

## Summary
Sets rest on undefined primitives (set, membership); everything else — subset, equality, union/intersection/complement/product/coproduct, power set, cardinality — is built from `∈` via explicit definitions that must be quoted exactly on exams. The chapter's algebra-of-sets law table is one of three parallel tables (Sets / Propositional Calculus / Boolean Algebra) used all term; recognizing the same law in any of the three languages is expected. Recursive definitions and induction (introduced informally here) become the primary tool in the Induction & Recursion notes, and set cardinality feeds directly into the Counting notes.
